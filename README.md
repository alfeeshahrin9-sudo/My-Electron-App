# My-Electron-App

A modern cross-platform desktop application that features a calendar, a notes app and weather app all at once! Built using Electron, HTML5, CSS3, and JavaScript.

## 🚀 Features

* **Cross-Platform:** Works seamlessly on Windows, macOS, and Linux.
* **Modern UI:** Styled using responsive and native-feeling CSS components.
* **Fast & Lightweight:** Optimized using vanilla JavaScript lifecycle scripts.

## 💻 How to Run the Application

Follow these step-by-step instructions to get the application up and running on your local machine for development or testing.

### 1. Prerequisites
Before you begin, make sure you have **Node.js** and **npm** installed on your system. You can verify your installation by running these commands in your terminal:
```bash
node -v
npm -v


2. Clone the Repository
Download a copy of the project files to your local machine:

Bash
git clone [https://github.com/alfeeshahrin9-sudo/My-Electron-App.git](https://github.com/alfeeshahrin9-sudo/My-Electron-App.git)
Then, navigate into the project directory:

Bash
cd My-Electron-App
3. Install Dependencies
Install the Electron framework and all necessary node modules required by the project:

Bash
npm install
This will generate a node_modules folder inside your project directory.

4. Launch the App
Run the start script to initialize the main Electron process and open the desktop window:

Bash
npm start
